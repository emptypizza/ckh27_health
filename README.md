# ckh27_health

증상, 수면, 복용한 약, 측정값을 날짜별로 남기고 진료 때 가져갈 요약을 만드는 개인 건강 관리 앱입니다. 서버 없이 브라우저에서만 동작하고, 기록은 암호로 암호화해 사용한 브라우저에 저장합니다.

- 앱: <https://emptypizza.github.io/ckh27_health/>
- 테스트 페이지: <https://emptypizza.github.io/ckh27_health/tests/>

기록을 정리하는 도구이며 진단이나 처방을 대신하지 않습니다.

## 사용 방법

1. 처음 열면 **건강 기록 암호**를 6자 이상으로 만듭니다. 다음부터는 이 암호로 잠금을 풉니다. 암호가 짧거나 짐작하기 쉬우면 백업 파일을 얻은 사람이 기록을 열 수 있으니, 길게 만들수록 안전합니다.
2. **일일 기록**에서 날짜를 고르고 기분·기력·스트레스(1~5), 몸무게, 수면, 체온, 맥박, 혈압, 증상, 복용한 약, 식사, 배변, 메모를 아는 것만 입력해 저장합니다. 아래 **최근 흐름**에서 최근 7·14·30일의 수면·기분·기력·스트레스 평균과 날짜별 기록을 볼 수 있습니다.
3. **기본정보**에 생년월일, 혈액형, 키, 알레르기, 진단받은 질환, 현재 처방, 의료기관을 적어 둡니다.
4. **진료 요약**은 고른 기간의 기록과 진료 때 물어볼 질문을 글로 정리합니다. 복사하거나 `진료요약-날짜.txt` 파일로 받아 가져갑니다.
5. 다 쓰면 **기록 잠그기**를 누릅니다.

저장하지 않은 내용이 있으면 날짜를 바꾸거나 잠글 수 없습니다. 먼저 저장하거나 입력을 취소하세요.

## 기록이 저장되는 곳

- 기록은 이 앱을 연 **브라우저 안에만** 저장됩니다. 서버로 보내지 않으며, 페이지가 외부로 연결하지 못하도록 콘텐츠 보안 정책(CSP)으로 막아 두었습니다.
- 저장할 때 암호에서 만든 키(PBKDF2-SHA256 600,000회)로 암호화(AES-GCM 256)합니다. 암호는 어디에도 저장하지 않습니다.
- **암호를 잊으면 기록을 열 수 없고 복구할 방법도 없습니다.**
- 앱 화면은 주소를 아는 누구나 열 수 있지만, 각자 자기 브라우저에 있는 기록만 볼 수 있습니다.

### 백업과 다른 기기에서 쓰기

- **암호화 백업 받기**는 `건강기록-암호화백업-날짜.json` 파일을 내려받습니다. 파일 내용도 암호화되어 있습니다.
- 다른 기기나 브라우저에서는 처음 화면의 **암호화 백업 선택**으로 그 파일을 고르고 같은 암호를 입력해 복원합니다.
- 브라우저 데이터를 지우면 기록도 지워집니다. 이 앱은 `emptypizza.github.io`의 다른 페이지와 브라우저 저장 공간을 함께 쓰므로, 백업을 주기적으로 받아 두는 것이 안전합니다.
- 기록 형식과 암호화 방식은 fortune-report의 건강 관리 기능과 같습니다. 그 앱에서 받은 암호화 백업을 같은 암호로 복원할 수 있습니다.
- 암호를 잊어 처음부터 다시 시작하려면 브라우저의 사이트 데이터에서 `ckh27_health:vault:v1` 항목을 지웁니다. 지운 기록은 되돌릴 수 없습니다.

### 건강 기록 JSON 추가

잠금을 푼 상태에서 **건강 기록 JSON 추가**로 암호화하지 않은 기록 파일(1MB 이하)을 합칠 수 있습니다. 이미 기록이 있는 날짜는 그대로 두고 없는 날짜만 추가하며, 기본정보는 비어 있는 항목만 채웁니다.

```json
{
  "version": 1,
  "profile": { "birthDate": "1990-05-15", "bloodType": "A+", "heightCm": 172.5 },
  "entries": [
    { "date": "2026-11-21", "sleepHours": 8, "mood": 4, "symptoms": "두통", "meals": "아침 거름" }
  ]
}
```

- `profile`: `birthDate`, `bloodType`, `heightCm`, `allergies`, `conditions`, `medications`, `clinician`
- `entries`의 각 항목: `date`(필수), `weightKg`, `sleepHours`, `mood`, `energy`, `stress`, `temperatureC`, `pulse`, `systolic`, `diastolic`, `symptoms`, `medications`, `meals`, `bowel`, `notes`

## 로컬에서 실행

빌드 과정이 없습니다. 저장소 폴더에서 정적 서버를 띄우고 브라우저로 엽니다.

```sh
python3 -m http.server 8000
```

<http://localhost:8000/> 으로 엽니다. 브라우저는 https와 localhost에서만 암호화 기능을 주므로, `index.html` 파일을 직접 열면 동작하지 않습니다.

## 테스트

`tests/` 페이지(<http://localhost:8000/tests/>)를 열면 기록 검증, 진료 요약, 암호화 테스트 9개가 그 브라우저에서 실행되고 결과가 표시됩니다.
